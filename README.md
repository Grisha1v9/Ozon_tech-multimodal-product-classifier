# Ozon Tech Challenge: Мультимодальная классификация товаров

Решение задачи бинарной классификации товаров (бан/не бан) для двух категорий: **БАД** и **легковоспламеняющиеся товары**.

## Задача

По текстовому описанию и до 5 изображениям товара определить, соответствует ли он правилам маркетплейса.

## Данные

- **13 000+** товаров
- Текстовые поля: `name`, `description`, `category`
- Изображения: до 5 JPG/PNG на товар
- Целевая переменная: `label` (1 — качественный, 0 — некачественный)

## Подход

1. **Извлечение эмбеддингов**  
   Использована предобученная модель `Qwen/Qwen3-VL-Embedding-2B` для получения текстовых и мультимодальных эмбеддингов (текст + изображения). В финальном решении применялись только текстовые эмбеддинги.

2. **Обучение классификаторов**  
   - Logistic Regression  
   - LightGBM  
   - Подбор порогов по `macro F1`

3. **Rule‑based признаки**  
   Добавлены бинарные признаки на основе регулярных выражений, кодирующие экспертные правила площадки (например, наличие маркировки БАД, спортивного питания, источников огня).

4. **Устранение утечек данных**  
   - Удалены полные дубликаты между train/val  
   - Исключена категория из текстовых признаков, чтобы модель не запоминала прямую связь «категория → метка»

5. **Генерация объяснений**  
   Реализованы два варианта:  
   - LLM‑генерация (Qwen3.5‑4B) с постобработкой  
   - Rule‑based генератор (быстрый, гарантирующий формат)

6. **Деплой**  
   Полный пайплайн упакован в Docker-контейнер с фиксированными версиями библиотек.

## Результаты

- **Macro F1** на публичном лидерборде: **0.6976** (текстовая модель с rule‑based объяснениями)  
- Формат ответа: `<комментарий>...<вердикт>` (бан / не бан)  
- В ходе экспериментов с мультимодальными эмбеддингами на валидации достигали **0.89**, но на скрытых данных качество падало из-за шума в изображениях и переобучения.
