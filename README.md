# Ozon Tech Challenge: Мультимодальная классификация товаров

Решение задачи бинарной классификации товаров (бан/не бан) для двух категорий: БАД и легковоспламеняющиеся товары.

## Задача

По текстовому описанию и до 5 изображениям товара определить, соответствует ли он правилам маркетплейса.

## Данные

- **13 000+** товаров
- Текстовые поля: `name`, `description`, `category`
- Изображения: до 5 JPG/PNG на товар
- Целевая переменная: `label` (1 — качественный, 0 — некачественный)

## Подход

1. **Извлечение эмбеддингов**  
   Использована предобученная модель `Qwen/Qwen3-VL-Embedding-2B` для получения мультимодальных эмбеддингов (текст + изображения).

2. **Обучение классификаторов**  
   - Logistic Regression  
   - LightGBM  
   - Подбор порогов по `macro F1`

3. **Rule‑based признаки**  
   Добавлены признаки на основе регулярных выражений, кодирующие экспертные правила площадки.

4. **Устранение утечек данных**  
   Удалены дубликаты, исключена категория из признаков.

5. **Деплой**  
   Полный пайплайн упакован в Docker-контейнер с фиксированными версиями библиотек.

## Результаты

- **macro F1** на публичном лидерборде: `0.69`
- Формат ответа: `<комментарий>...<вердикт>` (бан / не бан)
